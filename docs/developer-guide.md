# دليل المطوّر — ربط مراسيل (Marasil)

دليل عملي لربط مشروعك بمنصة مراسيل وإرسال رسائل واتساب عبر API بدون مشاكل.

## الفكرة الأساسية

**كل جهاز = مفتاح إرسال واحد يُنشأ تلقائياً.**  
لا تنشئ مفاتيح API يدوياً. افتح الجهاز، انسخ المفتاح، وأرسل.

## 1) ابدأ من لوحة التحكم

1. سجّل حساباً وتحقق من رقم واتساب (OTP).
2. فعّل اشتراكاً (تجربة مجانية أو خطة مدفوعة بعد الموافقة إن لزم).
3. من **الأجهزة** أنشئ جهازاً وامسح QR من واتساب → الأجهزة المرتبطة.
4. انتظر حالة **متصل**.
5. من قسم **ربط مشروعك البرمجي** انسخ **API Key** فوراً (يُعرض مرة واحدة فقط).
6. خزّن المفتاح في متغير بيئة على السيرفر: `MARASIL_API_KEY=...`

## 2) Base URL

```
https://YOUR_DOMAIN/api/v1
```

محلياً غالباً:

```
http://localhost:8080/api/v1
```

## 3) المصادقة

```http
Authorization: Bearer mrs_live_...
```

مفتاح الجهاز **لا يحتاج** `device_id` في جسم الطلب.

إذا فقدت المفتاح: من صفحة الجهاز اضغط **تجديد المفتاح** (يلغي القديم فوراً).

## 4) إرسال رسالة نصية

```bash
curl -X POST "https://YOUR_DOMAIN/api/v1/messages/text" \
  -H "Authorization: Bearer mrs_live_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: order-1001" \
  -d '{
    "to": "+9639XXXXXXXX",
    "message": "مرحبا من مراسيل"
  }'
```

### قواعد مهمة

- الرقم بصيغة **E.164** فقط (`+` ثم الدولة ثم الرقم).
- أرسل لمستلمين **موافقين** فقط.
- ضع `Idempotency-Key` فريداً لكل عملية منطقية.
- الاستجابة `202` تعني **قبول الطلب في الطابور** وليست تأكيد وصول للمستلم.

## 5) متابعة الحالة

```bash
curl "https://YOUR_DOMAIN/api/v1/messages/{message_ulid}" \
  -H "Authorization: Bearer mrs_live_YOUR_KEY"
```

أو من الواجهة: `/messages`

## 6) إشعارات النتيجة

### الطريقة السهلة

من `/webhooks` فعّل تنبيهات واتساب/اللوحة عند فشل الإرسال — بدون سيرفر.

### رابط سيرفر (اختياري للمطورين)

اربط URL يستقبل أحداث مثل `message.sent` و `message.failed` مع التحقق من HMAC.

## 7) أخطاء شائعة

| الرمز | الحل |
|------|------|
| `SUBSCRIPTION_REQUIRED` | فعّل/جدّد الاشتراك |
| `MESSAGE_QUOTA_EXCEEDED` | انتظر دورة جديدة أو رقِّ الخطة |
| `DAILY_DEVICE_QUOTA_EXCEEDED` | انتظر اليوم التالي أو رقِّ الخطة |
| `DEVICE_NOT_CONNECTED` | أعد ربط الجهاز بـ QR |
| `DEVICE_KEY_REQUIRED` | لا تنشئ مفتاحاً يدوياً — استخدم مفتاح الجهاز |
